# 📊 Análise de vendas com Python

# 📌 Sobre o projeto
Este projeto foi desenvolvido com o objetivo de realizar uma análise exploratória de dados de vendas utilizando Python, buscando transformar dados de vendas em informações úteis para apoiar a tomada de decisões.
A análise utiliza uma base de dados fictícia contendo informações sobre produtos, preços, quantidades, cidades e datas das vendas.

# 🎯 Objetivos

* Analisar o faturamento das vendas;
* Identificar os produtos com maior faturamento;
* Analisar o faturamento por cidade;
* Identificar os períodos com maior faturamento;
* Criar visualizações para facilitar a interpretação dos dados;
* Utilizar Python para manipulação e análise de dados.

# 🛠️ Tecnologias utilizadas

* Python
* Pandas
* Matplotlib
* Google Colab
* Jupyter Notebook
* GitHub

# 📊 Análises realizadas

Durante o projeto foram realizadas análises de:

* Faturamento total;
* Faturamento por produto;
* Faturamento por cidade;
* Faturamento por data;
* Identificação dos produtos e períodos de maior desempenho;
* Visualização dos resultados por meio de gráficos.

# 🔎 Principais resultados

A análise permitiu identificar padrões de faturamento na base de vendas, destacando os produtos, cidades e períodos que apresentaram melhor desempenho.

Entre os resultados encontrados, São Paulo apresentou o maior faturamento entre as cidades analisadas.

Também foi realizada uma análise por data, permitindo identificar os dias com maior volume de faturamento.

# 🤖 Inteligência Artificial

O projeto também contempla uma proposta de utilização de Inteligência Artificial para apoiar a interpretação dos resultados da análise de dados.

A integração com uma API de IA foi estudada durante o desenvolvimento do projeto, buscando utilizar modelos de linguagem para gerar interpretações e insights a partir dos dados analisados.

# ▶️ Como executar

1. Acesse o arquivo analise_vendas.ipynb;
2. Abra o notebook no Google Colab ou em um ambiente Jupyter;
3. Certifique-se de que o arquivo vendas.csv esteja disponível na pasta dados/;
4. Execute as células do notebook em ordem.
